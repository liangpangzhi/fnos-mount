大家好，分享一个自己写的小工具：[b]FnosMount（NAS 磁盘映射器）[/b]。

它解决的是一个很具体的麻烦：家里 NAS 上的共享目录，在 Windows 上每次都要「此电脑 → 映射网络驱动器」走一遍，重装系统、换了 IP、开了新共享就得再来一次；要挂 NFS 或 WebDAV 还得记一堆命令和端口。这个小工具把这套流程做成了一个窗口点几下的事。

[b]注意：它不是飞牛上的插件，而是 Windows 端的小客户端[/b]（单文件 exe，免安装，不需要 Python）。

[b][size=4]主要功能[/size][/b]

[list]
[*][b]自动发现[/b]：mDNS、SSDP/UPnP、WS-Discovery 三路并行探测，同时按 Web 指纹识别品牌。组播不通的环境（部分路由器/AP 隔离）会自动回退到网段端口扫描，我有一次就是这么找到设备的
[*][b]一键挂载[/b]：SMB、NFS、WebDAV 三种协议都能挂成真实盘符（Z:、Y: …），不是快捷方式，资源管理器、播放器、下载工具都能直接访问
[*][b]共享目录枚举[/b]：选好设备点「读取共享目录」，直接列出 NAS 上的共享名（中文名正常），下拉选择即可，不用手敲路径
[*][b]凭据安全[/b]：密码存进 Windows 凭据管理器，配置文件里不写明文；也支持匿名访问
[*][b]持久映射 + 自动重连[/b]：勾上之后生成持久映射，后台隔一段时间检查一次，NAS 重启或网络抖动导致掉盘会自己接回去
[*][b]开机自启 + 系统托盘[/b]：登录后静默进托盘并恢复磁盘，不占任务栏
[*][b]单实例[/b]：重复双击不会开一堆窗口，而是把已经开着的窗口叫到前面
[*][b]大文件传输优化（可选）[/b]：一键写入 SMB 客户端并发参数和 NFS 的 128KB 读写块，可随时还原原值
[/list]

[b][size=4]怎么用（4 步）[/size][/b]

[list=1]
[*]下载解压，双击 [b]FnosMount.exe[/b]（首次运行 Windows 可能提示，选择「更多信息 → 仍要运行」）
[*]点「扫描局域网」，左侧列表出现设备后点一下，NAS 地址自动填入
[*]点共享目录右侧的「读取共享目录」，在下拉框里选要挂的共享；选协议和盘符，需要账号就填用户名密码
[*]点「映射为本地磁盘」，完成。以后要断开，在下方列表选中它点「断开所选磁盘」
[/list]

想让它在重启后自动挂回来：在右侧「系统设置」里勾上「开机自动启动」+「保持映射」。

[b][size=4]运行环境[/size][/b]

[list]
[*]Windows 10 1809 及以上（Win11 正常），x64
[*]单文件 exe，约 8.4 MB，绿色免安装，不需要 Python 或任何运行库
[*]只使用 Windows 自带的网络挂载能力，[b]不需要在 NAS 上装任何东西，也不会改飞牛的配置[/b]
[/list]

[b][size=4]常见问题[/size][/b]

[b]Q：扫描不到 NAS？[/b]
先确认电脑和 NAS 在同一网段。有些路由器会拦截组播，这时点「深度扫描」——它会扫整个网段并做 HTTP 指纹识别，慢一点但基本都能找出来；也可以在顶部「手动 IP」里直接填 NAS 地址点「添加」。

[b]Q：NFS 挂载失败？[/b]
Windows 侧要先启用 NFS 客户端：控制面板 → 程序 → 启用或关闭 Windows 功能 → 「NFS 服务」→ 勾选「NFS 客户端」，重启后生效。飞牛侧需要在共享文件夹里开启 NFS 并允许你的网段访问。

[b]Q：WebDAV 连不上？[/b]
飞牛 WebDAV 默认端口是 5005，地址类似 http://192.168.1.10:5005/ （以实际为准）。另外 Windows 的「WebClient」服务必须处于运行状态（services.msc → WebClient → 启动，并设为自动）。

[b]Q：Windows Defender / 杀软报毒？[/b]
PyInstaller 打包的单文件 exe 比较容易被启发式误报，源码和打包脚本都在仓库里，可以自己打包，或者加个白名单。

[b]Q：勾了开机自启但登录后没反应？[/b]
请用 v1.0.1 及以上版本（v1.0.0 有“登录后进程直接退出”的 bug）。另外任务管理器「启动」里如果被禁用过，程序会在日志里提示，去那里重新启用即可。

[b]Q：重启后盘符不见了？[/b]
勾上「开机自动启动」和「保持映射」，或者至少勾「登录后自动重连（持久映射）」。托盘里也有「立即重连磁盘」。

[b]Q：密码会泄露吗？[/b]
不会写进配置文件，走 Windows 凭据管理器（DPAPI）。卸载时可以在「凭据管理器 → Windows 凭据」里删掉 FnosMount 相关条目。

[b][size=4]已知限制（先说清楚）[/size][/b]

[list]
[*][b]只支持 Windows[/b]。macOS / Linux 端没有做，系统调用差异太大
[*]飞牛 fnOS 上做过完整实测（设备发现、读 16 个共享、SMB 挂载与断开都正常）；[b]群晖和威联通做了设备发现与协议适配，但手头没有真机，没验证过[/b]，有设备的朋友帮忙试一下，有问题我改

[*]界面是纯 Win32 手写的（没用 Qt / Electron），所以只有一个窗口、样式比较朴素，好处是快、体积小
[/list]
